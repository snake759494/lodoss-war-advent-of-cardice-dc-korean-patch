# 기술 설명

## 디스크

드림캐스트 GD-ROM의 고밀도 영역은 트랙 3(LBA 45000부터)과 트랙 5로 이루어진 ISO9660이고, 게임 파일은 모두 트랙 5에 있습니다. `tools/gdfs.py`가 Redump BIN 5개로 LBA를 계산해 파일을 읽고, 섹터의 EDC/ECC를 다시 계산하며 파일을 제자리에 덮어씁니다. 바꾼 파일은 모두 원래 크기와 같아서 디스크 크기와 디렉터리는 바뀌지 않습니다.

## 문자열 (`1NOSDC.BIN`)

- 실행파일은 0x8C010000에 올라가며, 화면 문자열은 Shift-JIS이고 실행파일 안의 32비트 포인터(데이터 테이블·SH-4 리터럴 풀)로 참조됩니다.
- `work/cand_offsets.json`에 문자열 위치·길이와 포인터 위치를 정리했습니다. `S`는 이벤트 대사(화자 이름 + `\n` 줄바꿈 + `\0` 끝 등 자체 제어코드), `T`는 아이템·메뉴·시스템 문자열입니다.
- 한국어 문자열이 원래 자리보다 길면 실행파일 안의 여유 공간(쓰이지 않는 영역·정렬 여백·원문 자리)에 다시 배치하고 포인터를 고칩니다. 다른 문자열 안쪽을 가리키는 포인터가 있는 문자열은 옮기지 않고 제자리에서만 바꿉니다.
- 장비 부위 이름(목·허리·머리·귀·발)은 한 글자짜리 문자열로 따로 추가했습니다.
- 자주 쓰는 한글 일부는 대사 영역에서 1바이트 코드로 바꿔 공간을 줄입니다(게임의 반각 가나 코드 자리를 사용).

## 글꼴 (`DATANOS.BIN`)

게임 글꼴은 JIS 순서의 20×20 2bpp 글리프(100바이트) 표입니다. 비한자 영역(가나·기호·전각 영숫자)은 그대로 두고, **JIS 16구(제1수준 한자)부터 KS X 1001 한글 2,350자**를 순서대로 배정했습니다(`tools/kfont.py`, 둘째 바이트 0x5C·0x7F는 건너뜀). 따라서 한글은 Shift-JIS 한자 코드로 저장되고 게임 코드는 수정하지 않습니다.

## 이름 입력

이름 입력판은 실행파일 안의 가나 문자열 표(행당 0x34바이트, 2쪽)입니다. 이를 한글 자음×모음 음절표로 바꾸고(1쪽 ㄱ~ㅈ, 2쪽 ㅊ~ㅎ과 다른 모음, 마지막 줄 자주 쓰는 이름 글자), 버튼 그림은 텍스처에서 다시 그렸습니다.

## 사전 (`KANIMG.DAT`)

총람 항목은 제목·메타·본문으로 이루어지며 본문 안의 링크(`{{id|단어}}`)가 다른 항목으로 이어집니다. `tools/dictfmt.py`가 형식을 읽고 다시 쓰며, 한 쪽 23칸×8줄에 맞게 자동 줄바꿈합니다.

## 그림 글자 (`AKI.DAT`, `TAKIMG.DAT`)

- 텍스처는 [32바이트 헤더: 크기, 픽셀 형식(ARGB1555/RGB565/ARGB4444), 데이터 형식, 폭, 높이, 이름 16바이트] + PowerVR 데이터입니다. 데이터 형식은 twiddled, VQ(2×2 블록 코드북 256개), 작은 VQ, 직사각형 등이 쓰입니다(`tools/tex.py`).
- VQ 텍스처는 원래 코드북을 초기값으로 k-means를 돌려 같은 크기로 다시 인코딩합니다.
- 글자를 지울 때는 같은 버튼의 빈 부분 질감을 복사하거나, 글자 마스크 밖의 같은 줄 픽셀로 채웁니다. 원래 글자 색 그라데이션·외곽선·그림자를 표본으로 따서 한글을 그립니다(`tools/texpatch.py`).
- 한 라벨이 여러 텍스처 조각에 걸친 경우(타이틀 옵션 화면, 이름 입력 「공백」, 로드 「돌아가기」, 게임 안 옵션 「화면 조정」, 아이템 창 「내용」)는 조각 배치를 찾아 가상 화면으로 합성한 뒤 그리고, 다시 조각별로 나눠 넣습니다. 타이틀 옵션 화면은 8개 조각으로 이루어집니다(`tools/texspec.py`의 `_TILES`).
- 지역 이름 79종(`TAKIMG.DAT`)은 원래의 파란 외곽선 스타일로 두 줄까지 그립니다.

## 테스트 도구

`tools/emu.py`는 에뮬레이터를 백그라운드 창으로 띄워 키 입력을 보내고 화면을 캡처하는 개인 테스트용 도구입니다. `tools/sh4dis.py`는 포인터 참조 분석에 쓴 간단한 SH-4 디스어셈블러입니다.
